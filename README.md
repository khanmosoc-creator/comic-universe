# Super Zayd's Maze Guardians — `comic-universe`

An original, kid-friendly superhero comic website. Super Zayd leads the Maze Guardians — Dragoncrest,
Arrowlight, Bubbleguard and Zigzag — to protect the glowing Mazeverse from Grumblejaw, Blizzardbyte and
Splashfang.

The MVP is a **static site** (React + TypeScript + Vite) hosted free on **Cloudflare Pages**. There is no
server, database, account system, form, analytics or third-party script in the public site.

## Repository layout

| Path | What lives there |
| --- | --- |
| `apps/web/` | The public website (Vite + React + TypeScript). |
| `apps/web/src/content/*.json` | All comic content: characters, Issue #1 panels, universe lore, Art Vault. |
| `apps/web/public/art/owner/` | Owner-supplied sketches (WebP + PNG, metadata stripped). |
| `apps/web/public/art/{heroes,villains,panels,brand}/` | Original studio art generated by `tools/art/generate_art.py`. |
| `apps/web/public/_headers` | Cloudflare Pages security headers (strict CSP, no-referrer, etc.). |
| `tools/art/` | Offline, owner-controlled art workflow (sketch processing + vector art generator + fonts). |
| `services/api/` | Optional Java 21 / Spring Boot read-only content API for future expansion. **Not used by the site.** |
| `docs/` | Architecture guide, compliance checklist, design guide, asset manifest, approval workflow. |

## Run it locally

```bash
cd apps/web
npm ci            # or `npm install` the first time, before package-lock.json exists
npm run dev       # http://localhost:5173
npm run check     # type-check + production build into apps/web/dist
npm run preview   # serve the production build
```

Requires Node.js 20.19+ or 22.12+ (the repo pins 22 via `.node-version`).

## Cloudflare Pages settings

| Setting | Value |
| --- | --- |
| Production branch | `main` |
| Framework preset | None |
| Root directory | *(repository root)* |
| Build command | `cd apps/web && npm ci && npm run build` |
| Build output directory | `apps/web/dist` |
| Environment variable | `NODE_VERSION=22` (optional; `.node-version` already pins it) |

Equivalent with the root directory set to `apps/web`: build command `npm ci && npm run build`, output `dist`.

Client-side routes (`/heroes/zayd`, `/read/issue-1`, …) work on direct load and refresh because the build
contains **no `404.html`** — Cloudflare Pages then serves `index.html` for unknown paths (its SPA mode). No
catch-all `_redirects` rule is used, so static assets are never rewritten.

## Adding art or content

1. Sketches: drop the owner-approved PNGs into a folder and run
   `python3 tools/art/process_owner_art.py <folder> apps/web/public/art/owner` (strips metadata, trims, resizes).
2. Studio art: edit `tools/art/generate_art.py`, then `python3 tools/art/generate_art.py apps/web/public/art`.
3. Record every new file in `docs/asset-manifest.json` and follow `docs/art-approval-workflow.md`.
4. Story text lives in `apps/web/src/content/*.json`.

See `docs/architecture.html` for the full architecture, diagrams, compliance analysis and step-by-step guides.
